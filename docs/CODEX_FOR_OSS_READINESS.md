# Open-source maintainer readiness

This document summarizes public maintainer evidence for `design-asset-indexer`.
It intentionally contains no private application data, account identifiers, or secrets.

## Project status

- Public MIT-licensed repository.
- Active Windows / Photoshop maintenance scope.
- Current stable release: `v0.3.0`.
- Release artifacts include Windows x64 portable ZIP, wheel, sdist, and SHA-256 checksums.
- Cross-platform CI plus Windows GUI validation.
- Public security policy, contributor guide, maintainer workflow, roadmap, and structured issue templates.

## Maintainer responsibilities

Ongoing work includes:

- triaging user and compatibility reports;
- reviewing changes against source-preservation and frozen-plan safety boundaries;
- maintaining Windows / Photoshop compatibility;
- maintaining packaging, dependency notices, and release provenance;
- running release validation and publishing verified artifacts;
- preserving privacy by keeping user PSDs and sensitive paths out of public reports.

## Why the project matters

The project addresses a specialized but real workflow that is poorly served by generic asset tools: safely inspecting and batch-updating exact editable PSD attribution text while keeping processing local and preserving original source files. It also provides offline asset inventory and reporting tools.

## Honest usage note

The project is new. Do not infer broad adoption from this document. Application materials should state current public metrics truthfully and emphasize active maintenance, technical safety, privacy, and the underserved workflow rather than claiming usage that is not evidenced.
