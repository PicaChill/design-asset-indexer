Design Asset Indexer v0.3.0 - Windows x64 Portable
==================================================

1. Keep this directory fully extracted. Do not run the EXE inside the ZIP.
2. Start DesignAssetIndexer.exe. No external Python installation is required.
3. Check the Photoshop status shown at the top of the window.
4. Choose a PSD input folder. Use a separate, non-nested output folder.
5. Inspect text layers and review the planned changes.
6. Confirm only after the preview is correct. The app processes output copies
   and does not overwrite source PSD files.
7. Review the result and open the output folder from the result page.

PSD writing requires Windows and a separately installed Adobe Photoshop.
Photoshop and Adobe components are not included.

This executable is unsigned. Windows may show Unknown publisher or a
SmartScreen warning. Download only from the official GitHub Release and verify
the SHA-256 in SHA256SUMS.txt. Do not disable Defender or SmartScreen.

The package is standalone, not onefile, and has no installer, automatic update,
telemetry, or administrator requirement. Keep the bundled DLL and plugin files
next to DesignAssetIndexer.exe.
