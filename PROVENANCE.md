# Provenance

## Clean-room origin

This project is a clean-room reimplementation created by the user with Codex
assistance, starting from an empty directory. Its requirements come from a
written behavior specification for a local, offline design-asset workflow.

Two legacy scripts, `audit_assets.py` and `build_contact_sheets.ps1`, had
uncertain provenance. They were explicitly excluded: no source, structure, or
implementation text from those scripts was copied, migrated, or used as an
implementation input. Only independently stated capabilities and expected
behaviors were used as requirements.

All test images and archives are generated by `tests/generate_fixtures.py`
from simple geometry, colors, and test text. No private or third-party design
assets are included.

The opt-in Photoshop integration canary asks the user's local Photoshop to
create a minimal synthetic PSD in a temporary directory. That generated PSD is
deleted when the test ends and is never committed to the repository.

## Public specifications and documentation

- Adobe Photoshop File Formats Specification (PSD/PSB layout, image resource
  blocks, and thumbnail resource IDs 1033/1036):
  https://www.adobe.com/devnet-apps/photoshop/fileformatashtml/
- Python `zipfile` documentation (`ZipFile`, `ZipInfo`, CRC and size fields):
  https://docs.python.org/3/library/zipfile.html
- Python `pathlib` documentation:
  https://docs.python.org/3/library/pathlib.html
- Python `hashlib` documentation:
  https://docs.python.org/3/library/hashlib.html
- Pillow image API and installation documentation:
  https://pillow.readthedocs.io/en/stable/reference/Image.html
  https://pillow.readthedocs.io/en/stable/installation/basic-installation.html

These sources were used as format/API documentation, not as third-party source
code to copy.

## Dependencies and licenses

- Pillow (`Pillow>=10.0,<13`) is the cross-platform runtime dependency. Its PyPI metadata
  declares the `MIT-CMU` SPDX license expression:
  https://pypi.org/project/pillow/
- pywin32 (`pywin32>=306`) is an optional Windows-only dependency used to call
  the user's local Photoshop COM automation interface. Its installed package
  metadata declares the Python Software Foundation License.
- The Python standard library supplies filesystem, CSV/JSON, ZIP, hashing, and
  command-line support.
- Test/build extras are pytest and build; they are development tools and are
  not runtime dependencies.

New project code is released under the MIT License in `LICENSE`.
